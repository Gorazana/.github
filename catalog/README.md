## Maturity and ownership

Managed packages, publishable components and application-owned source are distinct modes with explicit support evidence. Go changes require rebuilding. Gorazine composes admin capabilities; Create is a proposed wizard. All package releases stay 0.x.x through actual field trials. No implementation claim follows from an icon or dossier.
